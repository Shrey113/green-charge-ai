# GreenCharge AI

## Charge Smart. Save Green. Stabilize the Grid.

---

## Project Overview

**GreenCharge AI** is an intelligent EV charging and renewable-energy optimization platform designed to make EV charging **smarter, cheaper, and greener**.

It uses **Google OR-Tools CP-SAT** to optimize schedules using:

-  Grid load and capacity
-  Renewable energy availability
-  Electricity cost
-  Charger availability
-  EV charging requirements

It shifts flexible charging to better time slots to reduce grid stress, cost, and renewable-energy waste.

---

## The Problem

As the number of Electric Vehicles increases, many EVs may charge at the same time, especially during evening peak hours.

This can cause:

-  High grid load and stress
-  Higher electricity costs
-  Poor renewable-energy utilization
-  Uneven charger utilization

---

## Our Solution

GreenCharge AI analyzes EV, grid, charger, and renewable-energy data and uses **constraint optimization** to generate a better charging schedule.

```text
EV + Grid + Renewable Data
            ↓
   Google OR-Tools CP-SAT
            ↓
 Optimized Charging Schedule
            ↓
 Lower Cost • Lower Peak Load • Greener Charging
```

## UI/UX Color Palette

GreenCharge AI uses a **minimal Green + White** visual theme to create a clean, trustworthy, sustainable, and user-friendly experience across all three dashboards.

### Primary Colors

| Color | Hex | Usage |
|---|---|---|
|  GreenCharge Green | `#16A34A` | Primary buttons, active states, key metrics |
|  Deep Green | `#15803D` | Hover states and stronger emphasis |
|  Soft Green | `#DCFCE7` | KPI backgrounds, success cards, highlights |
|  Very Light Green | `#F0FDF4` | Recommendations, selected areas, subtle backgrounds |

### Neutral Colors

| Color | Hex | Usage |
|---|---|---|
|  White | `#FFFFFF` | Cards, panels, navigation surfaces |
|  Soft Background | `#F9FAFB` | Main application background |
| ▫ Border Gray | `#E5E7EB` | Card borders, dividers, input borders |
|  Primary Text | `#111827` | Headings and important values |
| Secondary Text | `#6B7280` | Descriptions and supporting information |

### Functional Colors

| Status | Hex | Usage |
|---|---|---|
|  Success | `#16A34A` | Optimized, healthy, completed |
|  Warning | `#F59E0B` | High load, attention required |
|  Critical | `#EF4444` | Grid overload, charger failure |
|  Info | `#3B82F6` | Informational states and neutral alerts |

### Dashboard Color Usage

- **EV Driver:** White + Soft Green, with GreenCharge Green for savings, Green Score, and charging actions.
- **Grid Operator:** White + Green with restrained Warning/Critical colors for grid stress and alerts.
- **EV Network Operator:** White + Green with status colors for charger availability, utilization, and operational alerts.

### Design Principle

Use **green for positive actions and sustainability**, white for clarity, soft gray for structure, and warning/critical colors only when attention is required.

The interface should remain visually calm and consistent rather than becoming overly colorful.
